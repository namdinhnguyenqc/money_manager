# Finance & Cash Flow (Transactions, Wallets, Categories)

This feature enables owners to manage general cash flow (income and expenses), maintain multiple financial wallets/sources, and categorize entries using custom or standard categories.

## Folder Contents
- [flow.md](flow.md): User flow sequences for cash registers, transaction additions, and billing integrations.
- [rules.md](rules.md): Financial invariants, automatic balance calculations, and system-defined constraints.
- [state-machine.md](state-machine.md): Financial transaction statuses (PENDING, COMPLETED, VOIDED).
- [api-mapping.md](api-mapping.md): Endpoint mapping for transaction, wallet, and category routes.
- [mobile-integration.md](mobile-integration.md): Mobile client guidelines for transaction bookkeeping and multi-wallet states.
- [edge-cases.md](edge-cases.md): Negative wallet balances, deleting categories with active transactions, and bulk invoice settlements.
- [ui-behavior.md](ui-behavior.md): Sổ quỹ journal layouts, wallet switcher widgets, and transactional form behaviors.
