# Trading & Inventory Management

This feature enables landlords who run secondary services (e.g., selling bottled drinks, laundry tokens, dry snacks, or prepaid electricity cards) to track merchandise, manage costs, register sales, and analyze trading margins.

## Folder Contents
- [flow.md](flow.md): User flow sequences for merchandise imports (purchase) and sales.
- [rules.md](rules.md): Financial coupling guidelines, unit price splits, and stock regulations.
- [state-machine.md](state-machine.md): Trading item lifecycle (AVAILABLE vs SOLD).
- [api-mapping.md](api-mapping.md): Endpoint mapping for product imports, sales registries, and batch details.
- [mobile-integration.md](mobile-integration.md): Mobile client guidelines for scanning, counting, and dashboard integration.
- [edge-cases.md](edge-cases.md): Multi-package unpacking, loss of merchandise (wastage), and legacy database migration mappings.
- [ui-behavior.md](ui-behavior.md): Senior metrics cards (Vốn chưa bán, Lợi nhuận) and merchandise register drawer layouts.
