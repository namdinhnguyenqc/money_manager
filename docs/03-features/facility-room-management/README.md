# Facility & Room Management

This feature enables owners to create and manage boarding houses (facilities) and their associated rooms.

## Folder Contents
- [flow.md](flow.md): User flow sequences for facility and room CRUD.
- [rules.md](rules.md): Business rules for room status transitions and visibility.
- [state-machine.md](state-machine.md): Room status lifecycle.
- [api-mapping.md](api-mapping.md): Endpoint mapping for owner and rental room APIs.
- [mobile-integration.md](mobile-integration.md): Mobile client guidelines.
- [edge-cases.md](edge-cases.md): Dual-room systems and mock state bridging.
- [ui-behavior.md](ui-behavior.md): Facility cards, room drawers, and status indicators.
